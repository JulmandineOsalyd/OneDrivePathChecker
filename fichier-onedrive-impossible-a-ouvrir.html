Fichier OneDrive impossible à ouvrir : un chemin trop long ?

Le fichier est bien synchronisé, mais il ne s'ouvre pas depuis l'Explorateur Windows. La cause est souvent un chemin de plus de 255 caractères.

Retour à l'accueil

Le symptôme

Le fichier apparaît dans votre dossier OneDrive, mais il ne s'ouvre pas depuis l'Explorateur Windows, ou Windows affiche une fenêtre d'erreur. OneDrive, lui, n'affiche aucune erreur de synchronisation et n'indique pas la longueur du chemin : le diagnostic est difficile sans outil dédié.

Exemple de fenêtre Windows affichée pour un document dont le nom est très long.

Pourquoi le fichier ne s'ouvre pas

Windows limite la longueur du chemin complet d'un fichier à 255 caractères. Ce chemin commence à la racine du disque et comprend le nom de votre session Windows et celui du dossier OneDrive, par exemple :

C:\Users\julie\OneDrive - Mon Entreprise\Projets\2024\Document important.docx

Entre 256 et 400 caractères, OneDrive synchronise le fichier sans erreur, mais Windows ne peut plus l'ouvrir directement depuis l'Explorateur. Au-delà de 400 caractères, c'est la synchronisation elle-même qui est bloquée (voir l'erreur « le chemin d'accès est trop long »).

Ouvrir le fichier en attendant

Le fichier reste accessible en ligne : ouvrez-le depuis OneDrive dans votre navigateur, ou depuis Teams.

Corriger durablement

  • Raccourcissez le nom du fichier.
  • Raccourcissez le nom de ses dossiers parents : supprimez les répétitions, les dates et les mentions « version finale ».
  • Remontez le dossier plus près de la racine de votre OneDrive.
Le nom de votre session Windows et celui du dossier OneDrive comptent dans les 255 caractères : sur un autre poste, le même fichier peut s'ouvrir sans problème.
